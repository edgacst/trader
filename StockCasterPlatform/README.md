# StockCaster Platform

StockCaster Live가 보낸 방송을 회원이 웹 브라우저에서 시청하고, 방송 종료 후 다시 볼 수 있는 로컬 방송 플랫폼입니다.

## 최초 준비

저장소에는 MediaMTX 실행 파일과 운영자 비밀번호가 포함되지 않습니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\setup-media-server.ps1
$env:AdminBootstrap__Password = "직접_정한_안전한_비밀번호"
```

비밀번호는 영문과 숫자를 포함해 8자 이상으로 지정해야 합니다. 환경 변수는 관리자 계정이 아직 없는 첫 실행에서만 필요하며, 실제 비밀번호를 `appsettings.json`이나 Git에 저장하지 마세요.

이메일 인증과 비밀번호 찾기를 운영하려면 다음 SMTP 환경 변수를 설정하고 `Email__RequireVerification=true`로 지정합니다. `Email__PublicBaseUrl`에는 실제 HTTPS 도메인을 입력합니다.

```powershell
$env:Email__SmtpHost = "smtp.example.com"
$env:Email__SmtpPort = "587"
$env:Email__SmtpUser = "noreply@example.com"
$env:Email__SmtpPassword = "메일_서비스_비밀번호"
$env:Email__From = "noreply@example.com"
$env:Email__PublicBaseUrl = "https://your-domain.example"
$env:Email__RequireVerification = "true"
```

## 실행

1. `Start StockCaster Platform.cmd`를 더블 클릭합니다.
2. 운영 화면이 열리면 서버 상태가 `정상`인지 확인합니다.
3. StockCaster Live의 송출 설정에 다음 값을 입력합니다.

   - 서버 URL: `rtmp://127.0.0.1:1935`
   - 스트림 키: 운영 화면에 표시되는 `보호된 스트림 키`

4. StockCaster Live에서 방송을 시작합니다.
5. 통합 랜딩 화면 `http://127.0.0.1:5075/`에서 회원가입한 뒤 라이브 화면으로 입장합니다.

회원 시청 화면은 `http://127.0.0.1:5075/live`, 운영 화면은 `http://127.0.0.1:5075/studio`입니다. 종료할 때는 `Stop StockCaster Platform.cmd`를 실행합니다.

## 통합 랜딩과 화면 구성

- `/`는 서비스 소개, 실시간 방송 상태, 일정, 회원등급, 회원가입·로그인을 제공하는 통합 랜딩 화면입니다.
- 회원가입이나 로그인에 성공하면 `/live` 회원 방송 시청 화면으로 자동 이동합니다.
- `/live`는 라이브 영상과 실시간 채팅, `/replays`는 방송 다시보기 화면입니다.
- `/studio`와 `/admin`은 운영자 전용 송출·회원·채팅 관리 화면입니다.

## 방송 안내와 송출 모니터링

- 운영 화면에서 방송 제목, 설명, 고정 공지, 방송 예정 시간을 저장할 수 있습니다.
- 저장한 내용은 회원 시청 화면과 방송 일정 영역에 자동 반영됩니다.
- 실시간 송출 모니터에는 방송 시간, 수신 속도, 누적 수신량, 영상 해상도, 오디오 형식, 오류 프레임, 녹화 상태가 표시됩니다.
- 방송 안내는 회원 데이터와 함께 SQLite에 저장되므로 서버를 다시 실행해도 유지됩니다.

## 자동 녹화와 다시보기

- 방송을 시작하면 서버가 영상을 자동 녹화하고, 방송이 끝나면 다시보기 목록에 자동 등록합니다.
- 회원용 다시보기 화면은 `http://127.0.0.1:5075/replays`입니다.
- 다시보기 목록은 누구나 볼 수 있지만 영상 재생은 프리미엄 회원과 운영자만 가능합니다.
- 관리자는 `http://127.0.0.1:5075/admin`에서 제목과 공개 여부를 변경하거나 영상을 삭제할 수 있습니다.
- 녹화 파일은 `StockCasterPlatform/App_Data/recordings`에 보관됩니다. 서버를 재시작해도 남아 있습니다.

## 회원과 채팅 관리

- 회원 화면 오른쪽 위의 `로그인 · 회원가입`에서 새 회원을 가입시킬 수 있습니다.
- 로그인한 회원은 라이브 화면 오른쪽 채팅창에 참여할 수 있습니다.
- 관리자 화면은 `http://127.0.0.1:5075/admin`입니다.
- 최초 운영자 아이디는 `admin`이며 비밀번호는 첫 실행 전에 `AdminBootstrap__Password` 환경 변수로 직접 설정합니다.
- 운영자는 회원 채팅을 10분·1시간·24시간·영구 제한하거나 즉시 해제하고 메시지를 삭제할 수 있습니다.
- 관리자 화면의 `채팅 운영정책`에서 고정공지, 슬로우 모드, 금칙어를 설정할 수 있습니다.
- 동일 메시지 반복과 10초 동안 5개를 초과하는 빠른 전송은 서버에서 자동 차단합니다.

## 회원 등급과 시청 권한

- 새로 가입한 계정은 `무료 회원`으로 등록되며 라이브 방송과 채팅을 이용할 수 있습니다.
- `프리미엄 회원`은 라이브, 채팅, 다시보기를 모두 이용할 수 있습니다.
- 운영자는 관리자 화면에서 회원 등급을 즉시 변경하거나 회원을 삭제할 수 있습니다.
- 회원과 운영자 정보는 `StockCasterPlatform/App_Data/stockcaster.db` SQLite 데이터베이스에 저장됩니다.
- 기존 `members.json` 회원은 최초 실행 시 자동으로 SQLite에 이전되며 원본 파일은 삭제하지 않습니다.

## 운영 보안

- 송출 연결 정보와 보안키는 로그인한 운영자에게만 표시됩니다.
- 보호된 스트림 키가 없는 RTMP 게시 연결은 MediaMTX에서 차단됩니다.
- 관리자는 관리자 화면의 `보안 설정`에서 비밀번호를 변경하고 송출 보안키를 재발급할 수 있습니다.
- 보안키를 재발급하면 StockCaster Live에 새 키를 다시 입력하고 저장해야 합니다.

운영자 비밀번호와 송출 보안키는 저장소에 커밋하지 않습니다.

## 현재 구현 범위

- StockCaster Live의 RTMP 방송 수신
- 브라우저 재생용 HLS 자동 변환
- 방송 상태, 시청 연결 수, 수신 속도, 방송 시간, 영상 해상도, 오디오 형식, 오류 프레임 표시
- 운영자 방송 제목·설명·고정 공지·예정 시간 관리
- 회원용 영상 화면, 투자 위험 고지, 동적 방송 일정과 고정 공지 영역
- 통합 랜딩, 회원가입·로그인 후 라이브 자동 연결, 반응형 서비스·회원 안내
- 서버 실행 시 MediaMTX 자동 시작 및 종료 시 정리
- 회원가입·로그인과 12시간 로그인 유지
- PBKDF2-SHA256 기반 비밀번호 해시 저장
- SQLite 기반 회원·운영자 데이터 저장과 기존 JSON 자동 이전
- 무료·프리미엄 회원 등급 및 라이브·다시보기 서버 접근 제어
- 운영자 비밀번호 변경과 RTMP 송출 보안키 인증·재발급
- 운영자·방송 진행자·채팅 관리자 권한 분리
- 로그인 IP/계정별 시도 제한과 15분 자동 차단
- 이메일 인증·비밀번호 재설정·회원 탈퇴·약관 및 개인정보 동의
- 채팅 신고 접수·관리자 처리·관리자 활동 로그
- 방송 상태 이상 감지와 운영자 알림 이메일(Alerts 설정 시)
- 브라우저 기반 방송 예약 알림
- WebSocket 실시간 채팅과 최근 300개 메시지 보관
- 관리자 고정공지·금칙어·슬로우 모드와 서버 도배 방지
- 회원별 기간·영구 채팅 제한 및 메시지 삭제
- 방송 자동 녹화, 회원 다시보기 재생, 관리자 다시보기 관리

## 외부 공개 전 필수 작업

현재 설정은 한 컴퓨터 또는 내부 테스트 네트워크에서 검증하기 위한 MVP입니다. 불특정 다수에게 공개하기 전에는 도메인과 HTTPS, SMTP 비밀정보, 방송 키 보호, 방화벽, 녹화 보관 기간, 동시 접속 부하 시험, 이용약관·개인정보처리방침의 법률 검토를 적용해야 합니다.
